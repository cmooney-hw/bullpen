# Bullpen

Desktop widget showing the Highwater calling team's live JustCall Sales Dialer numbers. Windows only.

Install: download `Bullpen-Setup-<version>.exe` from the latest release and run it. The app updates itself from this repo's releases.

Publish a new version: bump `version` in `package.json`, commit, then run `./release.sh`. GitHub Actions builds the installer and publishes the release.
